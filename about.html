What this system is and is not.
about.md

AI Investor is a self-hosted investment research system running entirely on local hardware (Ollama, RTX 3090 -- no external LLM API, no cloud inference, no paid data feeds). It screens a 600+ security universe across three tracks (large-cap, Russell 2000, crypto), writes and archives investment theses with the local reasoning model, manages a simulated paper portfolio with real risk controls (stop-loss, position-weight caps, inverse-volatility sizing), and grades its own track record against passive benchmarks so it's clear whether it's actually finding anything.

This system never executes a trade. Broker API keys stay empty in .env on purpose. It proposes and analyzes; a human approves and executes manually, if ever. The paper portfolio is local bookkeeping against real market prices.

Full architecture writeup, engineering decisions, and the honest (including unflattering) results: github.com/cliteka-cell/ai-investor-writeup. Source code is private -- it touches personal financial data and a Telegram session.
