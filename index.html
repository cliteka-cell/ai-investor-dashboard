Self-hosted investment research system running entirely on local hardware (Ollama, no external LLM API). A three-layer screener covers large-cap, Russell 2000, and crypto; a living paper portfolio tests the picks against real prices with real risk controls; a calibration job grades the screener's own track record against passive benchmarks, honestly. This system never executes a trade -- broker API keys stay empty in .env on purpose. Everything below is simulation.
